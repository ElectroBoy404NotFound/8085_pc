# 8085_pc
Files of my attempt of making a 8085 based pc on a breadboard

Nothing to tell to be honest... `tests` contains the .asm files I used to debug why the build wasn't working.

`schematics.pdf` is the file with the circuit.

I wasn't really able to complete as my components were defective

# What the project is
It is basically a baremetal computer based around an Intel 8085 Processor aimed t printing text to a 16x2 lcd.

# What it uses (component list/BOM)
1. NEC D8085AC-2 (Processor)
2. 8155-2 (IO and RAM chip)
3. 28C16 (Parallel EEPROM)
4. 74HC139 (Address decoding logic)
5. 74HC573 (Address latch)

# Current status
As mentioned above, the build I did isn't completely function due to defective parts
